# MCSR Shuffle helper

This very simple mod is supposed to act as a helper to [MCSR Shuffle](https://github.com/bobikSR/MCSR-Shuffle-py). 
It disables the "Save and Quit to Title" and "Open to LAN" buttons, which helps prevent misclicks. 
After the run is completed (from SpeedrunIGT's perspective, meaning it's not category dependent), the buttons become enabled again.
It is incompatible with SeedQueue as it is recommended to use the program without it.
Install the latest version at the [releases page](https://github.com/bobikSR/mcsr-shuffle-helper/releases).
